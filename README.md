# Meme Generator Web App (Strona z memami)

##  Opis projektu
Projekt przedstawia dynamiczną aplikację internetową służącą do generowania własnych memów. Aplikacja pozwala użytkownikowi wybrać szablon obrazka, wprowadzić własny tekst (górny i dolny), wybrać kolor czcionki oraz dostosować pozycję tekstu na osi Y. Projekt powstał jako podsumowanie 28 lekcji kursu programowania w Pythonie.

##  Główne funkcjonalności i technologie
* **Backend (Flask):** Dynamiczne zarządzanie zawartością strony, przetwarzanie żądań użytkownika i renderowanie szablonów.
* **Frontend do Backend Data Transfer:** Przesyłanie formularzy (selektory, pola tekstowe) do warstwy logicznej aplikacji.
* **Przetwarzanie obrazu:** Generowanie napisów na memach na podstawie parametrów podanych przez użytkownika.
* **Clean Code:** Kod źródłowy napisany w pełnej zgodności ze standardami **PEP8**.
